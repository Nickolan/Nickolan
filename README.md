## 👨‍💻 About me

I'm a **Software Developer** with an **Associate Degree in Computer Programming** from the Universidad Tecnológica Nacional (UTN – Mendoza) and **2+ years of professional experience** building web and mobile applications and automating processes.

My focus is on **cybersecurity and DevSecOps**: my thesis project automates web security assessments by orchestrating tools like OWASP ZAP, Nuclei, ffuf and SQLMap. I work with AI coding agents following **Spec Driven Development (SDD)** to ship robust, scalable and secure software faster.

- 🤖 **AI-assisted development** with Claude Code, GitHub Copilot and Gemini
